# BikeSpot
A console application for automating short-term bicycle rentals, featuring catalog filtering, data import from CSV files, and report export to XLSX format.
BikeSpot

Консольное приложение на Python для автоматизации проката велосипедов.

Описание

В коде реализованы следующие компоненты:

• Базовое текстовое меню управления программой.

• Добавление новых велосипедов в каталог с указанием их уникального номера, названия, типа (горный, детский, городской) и стоимости за сутки.

• Фильтрация каталога по четырем критериям одновременно: по названию, типу, доступности и максимальной цене.

• Сортировка списка велосипедов по цене, а при одинаковой стоимости — по их ID.

• Автоматическое сохранение каталога и чтение настроек путей из конфигурационного JSON-файла.

Структура проекта

• src/main.py — главный файл со всей логикой каталога и интерфейса.

• data/config.json — конфигурационный файл с путями к базе данных.

• tests/test_plan.txt — текстовый тест-план для проверки программы.

#Запуск

Программа запускается из корневой папки проекта командой:

python src/main.py
